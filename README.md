# Nodal Analysis

Developed a well performance analysis model using **Inflow Performance Relationship (IPR) and 
Tubing Performance Relationship (TPR) to evaluate production behavior under different operating conditions.

The project analyzes the relationship between production rate and flowing bottom-hole pressure** and compares
well performance for 1.90-inch, 2.375-inch, and 2.875-inch tubing sizes**. 
The IPR and TPR curves are integrated to study well deliverability and identify operating conditions.

## Key Features

- Generated and analyzed IPR curves for the well.
- Evaluated TPR performance** for 1.90", 2.375", and 2.875" tubing.
- Compared the effect of tubing size on well deliverability**.
- Plotted IPR and TPR curves against production rate and flowing BHP.
- Used nodal analysis to study well operating conditions and production performance.
- Visualized well performance through comparative IPR–TPR plots.
